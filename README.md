### 🏠 Self-Hosted Infrastructure

Personal homelab running multiple services on Docker with modern DevOps practices.

**Platform & Tools:**

- **PaaS:** Coolify (self-hosted deployment platform)
- **DNS & CDN:** Cloudflare (domain management, security, caching)
- **VPN:** Tailscale (secure remote access)
- **Container Orchestration:** Docker + Docker Compose

**Services Running:**

- 🔐 **Vaultwarden** - Self-hosted password manager
- 📊 **Uptime Kuma** - Infrastructure monitoring
- 🛡️ **AdGuard Home** - Network-wide ad blocking & DNS
- 📸 **Immich** - Self-hosted photo management

**Infrastructure:**

- **Server OS:** Debian 13 (headless via SSH)
- **Hardware:** Lenovo IdeaPad 3 repurposed as home server
- **Access:** Remote management through SSH + Tailscale mesh network
- **Deployment:** Git-based CI/CD with Coolify
